# web

Full-stack TanStack Start application (the BFF in front of the Elysia API) with authentication, authorization, and file uploads.

## Setup

1. Copy the environment file:

```bash
cp .env.example .env
```

2. Configure environment variables in `.env`:

```env
# AWS
AWS_REGION="us-east-1"

# Backend (the Elysia API this BFF forwards to)
BACKEND_INTERNAL_URL="http://localhost:4000/api/v1"

# Cognito (OIDC login)
COGNITO_CLIENT_ID=""
COGNITO_DOMAIN=""
COGNITO_USERPOOL_ID=""

# Session cookies (generate with: openssl rand -base64 32)
SESSION_SECRET=""

# Email
RESEND_API_KEY="your-resend-api-key"
FROM_EMAIL="noreply@yourdomain.com"
CONTACT_TO_EMAIL="contact@yourdomain.com"

# Application
BASE_URL="http://localhost:3000"

# Monitoring
SENTRY_DSN="your-sentry-dsn"
```

> **Build once, deploy many.** These are plain runtime environment variables, not `VITE_*` — they're read from `process.env` when the container starts, never baked into the JS bundle at build time. The same built Docker image can be promoted from dev to prod unchanged; only the container's runtime env differs between environments.

## Development

Start the development server:

```bash
bun run dev
```

The application runs at `http://localhost:3000`

Build for production:

```bash
bun run build
```

Start production server (Nitro output in `.output/`):

```bash
bun run start
```

Type checking:

```bash
bun run check-types
```

## Project Structure

```
src/
├── routes/           # File-based routes (pages, layouts, /api server routes)
├── routeTree.gen.ts  # Generated by the Vite plugin — committed, never edited
├── start.ts          # Global request/function middleware
├── server.ts         # Server entry (Sentry-wrapped fetch handler)
├── client.tsx        # Client entry (hydration)
├── router.tsx        # Router factory
├── config/           # Server-only env (@t3-oss/env-core)
├── components/       # Reusable UI components (atomic design)
├── features/         # Feature modules (server/, client/, components/, lib/queries.ts, schemas/)
├── lib/             # Shared clients and setup (ky API clients, QueryClient, useAppForm, CASL)
├── styles/          # Global styles and Tailwind config
└── utils/           # Helper functions
```
